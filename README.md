The **Zero-Data Intent Architecture** replaces probabilistic guessing with mathematical boundary conditions. Instead of allowing Large Language Models (LLMs) to make statistical inferences on mission-critical transactions, this engine enforces **Degrees of Freedom (DoF)** constraints at line-rate speed.

## Quick Start
1. **Install Dependencies:** pip install -r requirements.txt
2. **Run the API Gateway:** uvicorn app.main:app --host 0.0.0.0 --port 8000
